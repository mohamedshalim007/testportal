🚀 JMC Compiler Service

Installation Guide for Students

⚠️ Important: This installation requires administrator privileges. You only need to install this once on your computer.
✅ One-time setup: After installation, the compiler will start automatically whenever you visit the exam portal.

📋 Installation Steps

1 Download the installer

Click the button below to download the compiler service installer:

📥 Download JMCCompilerSetup.exe

File size: ~5MB · Version: 1.0.0

2 Run the installer
  1. Double-click JMCCompilerSetup.exe to start installation
  2. If Windows shows a security warning, click "Run anyway"
  3. You may see a User Account Control (UAC) prompt - click "Yes"
  4. Follow the on-screen instructions
3 Service starts automatically

The compiler service will start automatically after installation.

✅ You can verify it's running by visiting: http://localhost:5001/health

4 Start coding!

Return to the exam page and start writing and running code.

  • Select your programming language
  • Write your code in the editor
  • Click "Run Code" to execute
  • View output in the terminal

💡 Troubleshooting

  • Service not starting: Restart your computer and try again
  • Port 5001 in use: Check if another application is using port 5001
  • Permission denied: Make sure you ran the installer as administrator
  • Firewall blocking: Allow the service through Windows Firewall

🔧 Manual Commands (Advanced)

Run these in Command Prompt as Administrator:

  • Start service: sc start JMCCompiler
  • Stop service: sc stop JMCCompiler
  • Check status: sc query JMCCompiler
  • Uninstall: sc stop JMCCompiler & sc delete JMCCompiler
